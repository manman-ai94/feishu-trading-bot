# 资料库 (knowledge base)

这个文件夹里的 `.md` 和 `.txt` 文件，AI 回答问题时可以检索。

- 你在飞书里给机器人发“记住：……”，内容会追加到 `notes.md`。发“删除上一条”可以撤回。
- 整本的书、长文档：转成 `.md` 或 `.txt` 放进这个文件夹，可以建子文件夹。不用重启，下一次提问就能查到。
- 文件名以 `_` 开头的文件和这个 `README.md` 不会被检索。
- 你自己的笔记和放进来的文件只留在服务器上，不会上传到 GitHub。
- `library` 子文件夹例外：里面是根据公开来源整理的参考资料（例如段永平公开讲过的投资原则），每条都带出处，跟着代码一起发布。来源网址在同一文件夹里以 `_sources-` 开头的文件中。
